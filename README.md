### Description ###

The Pasitive Pet Academy website is an easy-to-use basic multi-page based website designed to provide information about the 
training academy and its services.
The website aims to give users a relaxed browsing experince and provide them with the necessary information.

### Features ###

-Simple and Clear Navigation

-Multiple html pages

-Informative content on pet care services

-Contact Information

-Enquiry Form

-User-friendly

-Consistent Layout

### Websit Pages ###

-Home:Introdues the pet training academy and provides an overview.

-About Us:Provides some background and mission of the academy.

-Services:Displays the available services and their respective prices.

-Individual Page:

-Calculate Fees:Calculates total fee for customer along with a discount calculator.

-Contact Us:Provides contact information and enquiry form.


### Developement Proccess ###

The website was developed by planning the layout and content of the pages.Low-fidelity wireframes were used to aid with the planning of the layout.The website was developed in Visual Studio Code and uploaded to GitHub for version control and Submission
